# SCENES.md — 포획 전투 연출 명세

- 원칙: 평상시 보드는 조용하게, 포획 순간 1~3초에만 카메라·조명·파티클을 집중한다
- 모든 연출은 프로시저럴(셰이더 + 파티클 + 카메라)로 구현한다. 외부 에셋 금지
- 연출 중 입력 잠금, 클릭/탭 시 즉시 스킵하고 최종 보드 상태로 점프

## 1. 구현 자산 (공통 부품, P3에서 제작)

- **디졸브 셰이더**: 노이즈 임계값 기반 소멸/생성, 경계선 발광(emissive edge). 색상 파라미터화 (초=청록, 한=진홍, 소멸=주홍→재)
- **충격파 링**: 바닥 평면에서 확장되는 링 메시 + 페이드
- **파티클 이미터**: 스파크(가산혼합 점), 재(중력 낙하 회전 사각), 혈흔(붉은 점 분사, 토글 대상), 연기(느린 상승 반투명)
- **바닥 데칼**: 혈흔 얼룩(토글 대상), 균열(방사형 라인) — 캔버스 텍스처 프로시저럴 생성
- **카메라 리그**: 대국 카메라 ↔ 연출 카메라 전환, 흔들림(트라우마 기반), 줌
- **화면 효과**: 붉은 플래시(전체 오버레이 1~2프레임), 배경 암전(주변 조도 하강), 히트스톱(80~120ms 시간 정지)
- **소환진**: 바닥 원형 문양(프로시저럴 SVG→텍스처, 팔괘/전통 문양 모티프) 회전 + 발광

## 2. Tier 1 공통 타임라인 (모든 포획의 기본 골격)

| 시각 | 연출 |
| --- | --- |
| 0.0s | 이동 완료, 입력 잠금. 배경 암전 시작, 연출 카메라로 전환(두 기물 측면 줌) |
| 0.3s | 공격 기물 아래 소환진 전개, 기물 각인 발광 + 균열 라이트 |
| 0.8s | 공격 실행 (Tier 2 고유 연출 구간, 기본값은 전방 돌진) |
| 1.2s | 타격: 히트스톱 → 붉은 플래시 → 충격파 링 + 스파크 + 혈흔 파티클 + 카메라 흔들림 |
| 1.5s | 피격 기물 디졸브 소멸(주홍 경계 발광 → 재 파티클 낙하), 바닥 혈흔 데칼 |
| 2.3s | 암전 해제, 공격 기물 발광 감쇠, 대국 카메라 복귀 |
| 2.8s | 입력 잠금 해제 |

## 3. Tier 2 기물별 고유 연출 (0.8s 공격 구간 교체)

- 각 항목에 정식판/간이판을 병기한다. 시간 압박 시 간이판으로 구현하고 `[~]` 표기

### 졸·병 — 창격

- 정식: 기물 앞에 빛의 장창 3개가 소환되어 순차 찌르기, 관통 라인 이펙트
- 간이: 직선 찌르기 라이트 빔 1회 + 스파크

### 차 — 돌진 참격

- 정식: 기물이 고속 돌진(잔상 트레일) → 교차 지점에서 X자 슬래시 아크 2개
- 간이: 돌진 트레일 + 슬래시 아크 1개

### 포 — 포격

- 정식: 기물 상공에 포문 문양 전개 → 발광 포탄이 포물선 낙하 → 폭발 링 + 연기 기둥
- 간이: 수직 낙하 발광탄 + 폭발 링

### 마 — 도약 강습

- 정식: 기물이 높이 도약(카메라 상향 추적) → 낙하 착지 충격파 + 지면 균열 데칼
- 간이: 점프 후 착지 충격파

### 상 — 진각 내려찍기

- 정식: 기물이 거대화 그림자와 함께 상승 → 내려찍기 → 방사형 균열 + 저주파 흔들림(카메라 흔들림 강)
- 간이: 스케일 펄스 + 강한 충격파 1회

### 사 — 호위검

- 정식: 원형 검막(회전하는 빛의 검 4자루) 전개 → 십자 베기 수렴
- 간이: 회전 링 이펙트 + 베기 플래시

### 궁 — 외통 승리 연출 (포획이 아닌 게임 종료 연출)

- 정식: 전체 화면 암전 → 승자 진영 문양 전개 → 슬로모션 최후 일격 리플레이 느낌의 카메라 회전 → "외통" 붓글씨 문구
- 간이: 암전 + 승자 색 발광 + "외통" 문구 오버레이

## 4. 15금 수위 가드

- 혈흔 = 파티클과 데칼까지만. 인체 묘사가 없으므로 절단·고어는 구조적으로 발생 불가
- 혈흔 OFF 시: 붉은 파티클 → 백금색 스파크로 대체, 데칼 미생성

## 5. 2.5D 캐릭터 실루엣 (스트레치, 실패해도 무방)

- 타격 순간(1.2s) 배경에 프리미티브 조립 로우폴리 무사 실루엣(검은 실루엣 + 진영색 림라이트)이 0.3초 잔상으로 나타났다 사라지는 컷인
- 기물 유형별 실루엣 차별화(창병/기마/거병 등)는 여력이 있을 때만
- 이 항목이 전체 일정을 위협하면 즉시 SKIP
