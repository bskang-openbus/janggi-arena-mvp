# PRD.md — Janggi Arena MVP 제품 명세

## 1. 제품 한 줄 정의

- 한나라 vs 초나라의 전통장기 대국에서, 말을 잡는 순간마다 기물이 발광·변형하며 상대를 처단하는 전투 연출이 재생되는 웹 3D 장기 게임

## 2. 대상·톤

- 대상: 장기를 아는 15세 이상 한국 사용자
- 톤: 전통(나무 장기판, 한자, 붓글씨 감성) x 판타지(발광, 소환진, 에너지 이펙트)
- 수위: 15세이용가 기준. 허용 = 붉은 혈흔 파티클, 바닥 혈흔 데칼, 재로 붕괴하는 소멸 연출, 타격의 무게감. 금지 = 신체 절단, 장기 노출, 시체 잔존, 고어 클로즈업
- 혈흔 표현은 설정에서 ON/OFF (기본 ON)

## 3. 범위

### 포함 (필수)

- 장기 룰 100% (RULES.md)
- 로컬 2인 대국 (한 화면 교대)
- Tier 1 공통 포획 연출 + Tier 2 기물별 고유 연출 7종 (각 1개)
- 결과 화면, 재시작, 연출 스킵, 혈흔 토글

### 포함 (스트레치)

- 온라인 1:1 (방 코드), 턴 타이머, 항복
- Web Audio 합성 사운드, 저사양 모드, Docker 배포

### 제외 (차기 버전)

- 가챠·수집·상점·결제, 랭킹·매치메이킹, AI 상대, 차림 선택, 점수제·덤, 무르기, 재접속 복구, 외부 3D 캐릭터 모델, 모바일 앱

## 4. 화면 구성

- **타이틀**: 로고 문구 "장기 아레나" (Pretendard, 붓글씨 느낌 스타일링), 버튼 = 로컬 대국 / 온라인(P5 완성 시) / 설정
- **대국 화면**: 3D 보드 중앙, 상단 턴·장군 표시, 좌우 잡힌 말 목록, 하단 패스·항복·설정 버튼
- **설정 오버레이**: 혈흔 ON/OFF, 사운드 ON/OFF, 저사양 모드
- **결과 오버레이**: 승패·무승부 사유, 재대국 버튼
- 데스크톱 우선, 모바일 브라우저에서 깨지지 않는 반응형 (터치 입력 동작)

## 5. 비주얼 방향 (외부 에셋 없이 달성)

- 보드: 프로시저럴 나무 머티리얼(노이즈 기반), 어두운 배경 + 보드에 집중된 조명
- 기물: 팔각기둥 + 상단 한자 각인(Canvas 텍스처). 초 = 청록 발광 엣지, 한 = 진홍 발광 엣지
- 연출 시 기물이 "각성"하는 콘셉트: 각인이 발광하고 균열에서 빛이 새어 나오며 이펙트가 전개 — 캐릭터 모델 없이 캐릭터성을 부여하는 핵심 장치
- 후처리: 블룸 필수, 비네트 약하게

## 6. 성능 목표

- 데스크톱 60fps, 모바일 브라우저 30fps 이상 (연출 중 순간 하락 허용)
- 연출 1회 길이: 공통 2.5~3.5초, 스킵 즉시 가능
- 초기 로드 5초 이내 (외부 에셋이 없으므로 달성 용이)

## 7. 성공 판정 (아침 기준)

1. `pnpm dev`로 실행 → 로컬 대국 1국을 룰 위반 없이 완주 가능
2. 7종 기물 포획 시 서로 다른 연출 재생
3. engine 테스트 전체 green, E2E 스크린샷이 artifacts/에 존재
4. PROGRESS.md에 페이즈별 완료 기록 존재
