# RULES.md — 장기 룰 명세 + 테스트 벡터 (P1의 감독관)

- 본 문서는 룰의 유일한 기준이다. 다른 문서·일반 상식과 충돌 시 본 문서가 우선한다
- 명세가 모호한 지점을 발견하면 대한장기협회 일반 규칙에 부합하는 방향으로 스스로 결정하고 DECISIONS.md에 기록한다

## 1. 보드와 좌표계

- 교차점 9줄(파일) x 10칸(랭크). 기물은 교차점 위에 놓인다
- 좌표 표기: 파일 `a`~`i` (초 진영 기준 왼쪽→오른쪽), 랭크 `1`~`10` (초 진영 아래→위)
- 초(楚)는 아래(랭크 1~4 궁성 측), 한(漢)은 위(랭크 7~10 궁성 측)
- 궁성: 초 = d1~f3 (3x3), 한 = d8~f10 (3x3)
- 궁성 대각선: 네 모서리와 중앙을 잇는 X자. 초 궁성의 대각 연결점 = d1-e2-f3, f1-e2-d3. 한 궁성 동형(d8-e9-f10, f8-e9-d10)
- 대각선이 있는 지점에서만 대각 이동이 가능하다 (예: e2에서는 4방 대각 가능, d2에서는 대각 불가)

## 2. 초기 배치 (차림 선택 없음, 고정)

- 배치는 "마상상마" 차림으로 양측 고정 (차림 선택 기능은 차기 버전)

```text
랭크10(한): a10 차, b10 마, c10 상, d10 사, f10 사, g10 상, h10 마, i10 차
랭크 9(한): e9 궁(漢王)
랭크 8(한): b8 포, h8 포
랭크 7(한): a7 병, c7 병, e7 병, g7 병, i7 병
랭크 4(초): a4 졸, c4 졸, e4 졸, g4 졸, i4 졸
랭크 3(초): b3 포, h3 포
랭크 2(초): e2 궁(楚王)
랭크 1(초): a1 차, b1 마, c1 상, d1 사, f1 사, g1 상, h1 마, i1 차
```

- 선수: **초가 먼저 둔다**

## 3. 기물별 이동 규칙

### 3.1 차 (車)

- 가로·세로 임의 거리, 경로에 기물이 있으면 그 앞까지. 적 기물 위치에는 포획 진입 가능
- 궁성 안(자기·상대 불문)에서 대각선 위에 있을 때, 대각선을 따라 직선 이동 가능 (예: d3→e2→f1 관통 가능, 경로 규칙 동일)

### 3.2 포 (包)

- 가로·세로로만 이동하며, 반드시 **정확히 1개의 기물(포다리)을 넘어야** 이동·포획 모두 가능
- 제약 3종:
  1. 포는 **포를 넘을 수 없다** (포다리가 포이면 불가, 아군·적군 불문)
  2. 포는 **포를 잡을 수 없다**
  3. 포다리 없이 한 칸도 움직일 수 없다
- 궁성 대각선 위에서는 중앙(e2/e9)에 포다리가 있을 때 대각 방향으로 모서리↔모서리 이동·포획 가능 (동일 제약 적용)

### 3.3 마 (馬)

- 직선 1칸 + 그 방향 바깥 대각 1칸 (총 8방)
- **멱**: 직선 1칸 지점에 기물이 있으면 해당 방향 이동 불가

### 3.4 상 (象)

- 직선 1칸 + 같은 방향 대각 2칸 (총 8방, 도착점은 (±2,±3) 형태)
- **멱 2곳**: 직선 1칸 지점, 그리고 첫 대각 1칸 지점에 기물이 있으면 불가

### 3.5 졸 (卒) / 병 (兵)

- 앞으로 1칸 또는 옆으로 1칸. **후퇴 절대 불가**
- 상대 궁성 안 대각선 위에서는 전진 방향 대각 1칸 이동 가능 (예: 초 졸이 d8에서 e9로, e9에서 d10/f10으로)
- 마지막 랭크 도달 후에도 승진 없음, 옆 이동만 가능

### 3.6 사 (士)

- 궁성 밖으로 나갈 수 없음. 궁성 내 선(가로·세로·해당 지점의 대각)을 따라 1칸

### 3.7 궁 (楚王/漢王)

- 사와 동일: 궁성 내 선을 따라 1칸

## 4. 대국 규칙

- **장군**: 다음 수에 궁이 잡힐 수 있는 상태. UI에 경고 표시
- **자살수 금지**: 두고 난 후 자기 궁이 장군 상태가 되는 수는 비합법
- **외통(체크메이트)**: 장군 상태이며 벗어날 합법 수가 없음 → 공격 측 승리
- **한수쉼(패스)**: 자기 턴에 두지 않고 넘길 수 있다. 단 **장군 상태에서는 패스 불가**
- **왕 대면(빅장)**: 두 궁이 같은 파일에서 사이에 기물 없이 마주 보게 되는 수는 합법이며, 발생 즉시 **무승부** 처리 (MVP 단순화 규정)
- **반복 무승부**: 동일 국면(배치+차례)이 3회 발생하면 무승부
- **장군 상태 + 합법 수 없음 + 패스 불가** = 외통 패배. 장군이 아닌데 이동 수가 없으면 패스하면 되므로 스테일메이트는 존재하지 않는다
- 점수제(한 1.5점 덤)·시간패는 엔진 범위 외 (P5 서버에서 타이머만 구현)

## 5. 테스트 벡터 (전수 구현 필수)

- 표기: `배치 / 차례` → `기대 결과`. 배치는 명시된 기물 외 빈 보드. 궁은 양측 항상 포함할 것 (미명시 시 초궁 e2, 한궁 e9)
- 아래는 핵심 벡터이며, **오케스트레이터는 각 기물·규칙마다 자체 벡터를 추가해 총 60개 이상**으로 확장할 것

### 차

- V01: 차 e5, 빈 보드 / 초 → e파일·5랭크 전체로 이동 가능 (16곳, 자기 위치 제외, 궁 위치 제외 처리 주의)
- V02: 차 e5, 초 졸 e7 / 초 → 위 방향은 e6까지 (e7 아군 차단)
- V03: 차 d3(초 궁성 대각 위) / 초 → e2 방향 대각 이동 가능, d2에서는 대각 불가 검증
- V04: 차 f10, 한궁 e9, 초궁 e2… 궁성 대각 관통: 차 d10 → e9(포획) 가능 여부 등 대각 경로 검증

### 포

- V05: 포 b3, 기물 b7 한 병, 그 외 b파일 빈 칸 / 초 → b8, b9, b10 이동 가능 + b7 너머만 (b4~b6 불가)
- V06: 포 b3, b파일에 기물 없음 / 초 → b파일 방향 이동 0개
- V07: 포 b3, b5 초 마, b7 한 병 / 초 → b7 포다리 아님: 기물 2개 초과라 b7 너머 불가, b6 이동만? → 정답: 포다리는 b5, 도착 가능 b6과 b7(포획). b7 너머는 기물 2개 개입으로 불가
- V08: 포 b3, b5 한 포 / 초 → 포를 넘을 수 없으므로 위 방향 0개
- V09: 포 b3, b5 초 졸, b8 한 포 / 초 → b8 포획 불가 (포는 포를 못 잡음), b6·b7만 가능
- V10: 포 d1(초 궁성 모서리), e2에 기물 존재 / → f3 대각 이동·포획 가능

### 마·상 (멱)

- V11: 마 e5, 빈 보드 / → 8곳 전부
- V12: 마 e5, e6에 기물 / → 위쪽 2곳(d7, f7) 불가, 나머지 6곳
- V13: 상 e5, 빈 보드 / → (±2,±3) 8곳 중 보드 내 전부
- V14: 상 e5, f6에 기물 / → f6을 경유하는 g8·h7 방향 불가
- V15: 상 e5, e6에 기물 / → 위 직선 시작 2방향(d8, f8) 불가

### 졸·병

- V16: 초 졸 e5 / → e6, d5, f5 (3곳). e4 불가
- V17: 한 병 e5 / → e4, d5, f5. e6 불가
- V18: 초 졸 e9(한 궁성 중앙) / → d10, f10 대각 전진 포함
- V19: 초 졸 d8 / → e9 대각 전진 가능, c8·d9 포함 확인

### 사·궁

- V20: 초 사 d2 / → d1, d3, e2 (대각 없음 지점이므로 3곳)
- V21: 초 궁 e2 / → 8방 전부 (중앙은 대각 포함)
- V22: 초 사 e2, 한 차 e6 / → 사가 e2를 떠나면? (관계없음) / 궁 노출 자살수 케이스는 V25에서

### 장군·외통·특수

- V23: 한 차 e6, 초 궁 e2, 사이 빈 칸 / 초 차례 → 초는 장군 상태 판정 true
- V24: V23 상태에서 초의 합법 수는 장군을 벗어나는 수만 생성되는지 검증
- V25: 자살수: 초 사 e3이 초 궁 e2와 한 차 e6 사이를 막고 있을 때, 사를 옆으로 옮기는 수는 비합법
- V26: 외통 구성 국면 1개를 직접 설계하여 checkmate=true 검증 (오케스트레이터 설계)
- V27: 왕 대면: 초 궁 e2, 한 궁 e9, e파일 사이 빈 칸을 만드는 수 → 즉시 무승부 판정
- V28: 장군 상태에서 pass 액션 → 비합법
- V29: 장군 아닌 상태에서 pass → 합법, 차례 전환
- V30: 동일 국면 3회 반복 시나리오 → 무승부 판정
